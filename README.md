# Mainkraff 🟩

Простая браузерная песочница из блоков в стиле Майнкрафта. Один файл, никакой установки.

## Как играть

Открой файл `index.html` в браузере (просто дважды кликни по нему) — и всё готово.

### Управление

| Действие              | Как                                   |
|-----------------------|---------------------------------------|
| Поставить блок        | Левая кнопка мыши (или тап на телефоне)|
| Сломать блок          | Правая кнопка мыши                    |
| Выбрать блок          | Цифры `1`–`8` или колёсико мыши       |
| Двигать камеру        | Стрелки на клавиатуре                 |
| 💾 Сохранить мир      | Кнопка вверху (сохраняется в браузере)|
| 🗑 Очистить           | Кнопка вверху — новый мир             |

## Что внутри

Чистый HTML + JavaScript, рисование на `<canvas>`. Мир сохраняется в `localStorage`
браузера, так что после сохранения он остаётся на месте при следующем открытии.
