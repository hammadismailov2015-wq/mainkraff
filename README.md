# Путь сподвижника — سبيل الصحابة

Историческая браузерная аркада о великих сражениях раннего Ислама. Ты играешь за
безымянного воина из числа сподвижников (сахаба). Оружие — **лук** и **меч**.
Проходишь путь от Бадра до Ярмука, отбивая волны противника.

> Из уважения к исламской традиции в игре **не изображаются** Пророк Мухаммад ﷺ
> и сподвижники. Ты видишь битву глазами воина. Каждый уровень открывается
> исторической справкой (год, стороны, значение сражения).

## Как играть

Просто открой `index.html` в браузере — сборка не нужна.

### Управление (ПК)
- **WASD / стрелки** — движение
- **Мышь** — прицел
- **ЛКМ / пробел** — атака
- **ПКМ / Q** — сменить оружие (меч ⚔️ ↔ лук 🏹)

### Управление (телефон/планшет)
- Левый джойстик — движение (прицел наводится на ближайшего врага)
- Кнопки ⚔️ / 🏹 — атака мечом/из лука, «СМЕНА» — смена оружия

Битвы после кончины Пророка ﷺ (632 г.) — эпоха войн Ридда, великих завоеваний
праведных халифов, а также походов Омейядов и Аббасидов.

Особые элементы: 🐘 **боевые слоны** (Кадисия, Нехавенд), 🏰 **штурм крепостных
стен** с проломом ворот. Крепость стоит там, где она была исторически: **Хайбар**
(крепости в оазисе), **Гелиополь** (крепость Вавилон) и **Осада Константинополя**.
У Хайбара крепость соседствует с оазисом.

После Нехавенда открывается **бонус-уровень «Современная битва»** — аркада вне
истории: техника (танк 🚜, самолёт ✈️, пушка 💥) против волн противника.
Переключение техники — клавишами `1`/`2`/`3` или `V`.

Битвы открываются по мере прохождения; пройденные доступны в «Выборе битвы».
Прогресс сохраняется в браузере (localStorage).

## Механика
- **Меч** — быстрый круговой удар по врагам вблизи.
- **Лук** — дальний выстрел; стрелы ограничены, пополняются с павших врагов.
- Волны врагов; часть противников стреляет из лука. В некоторых битвах в финале
  появляется усиленный полководец.
- Здоровье, счёт, индикатор волн — на верхней панели.
